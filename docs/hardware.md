# Hardware

The `hardware/` directory currently contains early hardware notes and KiCad work-in-progress.

## Target Design

The current design plan is based on:

| Component | Description |
|-----------|-------------|
| nRF54LM20A | Nordic SoC with BLE and proprietary radio |
| NAU88L21 | Audio codec |
| nPM1300 | PMIC |

!!! note
    Hardware is in early concept stage, subject to change.

## Schematic & Layout

KiCad project files are in `hardware/`. Refer to the schematic and layout for pin assignments and component details.
