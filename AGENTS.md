Read `README.md` and the relevant subdirectory README first.

- Default to `nrf_firmware/` for current firmware work.
- Use `rw612_firmware/` for legacy RW612/NXP reference code.
- Wi-Fi, UDP and raw 802.11/L2 mean RW612.
- Proprietary 2.4 GHz and nRF54LM20A board work mean nRF.
- BLE, USB Audio, USB CDC, and role selection may exist in either tree.
